# SupraCraft organization profile

This repository supplies the GitHub organization profile shown at `github.com/SupraCraft`.

- `profile/README.md` is the human-facing organization introduction.
- `https://supracraft.github.io/` is the SupraCraft project hub.
- Project documentation and releases remain with their owning repositories.

The profile stays intentionally small so the organization can span multiple technical domains without duplicating project information here.

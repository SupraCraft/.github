# SupraCraft public organization surface

This repository contains SupraCraft's public organization profile and shared GitHub community defaults.

- `profile/README.md` is the public organization front door shown at `github.com/SupraCraft`.
- Project-specific documentation, release surfaces, and product sites remain in their owning public repositories.
- The GitHub organization repository view is the automatically current catalog of public repositories; this repository does not maintain a duplicate hand-written inventory.

Organization branding and public-surface decisions are governed privately and only approved public-safe material is published here.

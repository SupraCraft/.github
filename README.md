# SupraCraft public organization surface

This repository contains SupraCraft's GitHub-native organization profile and shared GitHub community defaults.

- `profile/README.md` is the compact public front door shown at `github.com/SupraCraft`.
- `https://supracraft.github.io/` is the full branded SupraCraft organization hub and primary public discovery experience.
- Project-specific documentation, release surfaces, and product sites remain in their owning public repositories.
- GitHub's organization repository view remains the exhaustive, automatically current catalog of public repositories.

The GitHub profile stays intentionally thin. It points users toward the branded hub and native repository discovery rather than duplicating either surface.

Organization branding and public-surface decisions are governed privately and only approved public-safe material is published here.

# SupraCraft

**Shared craftsmanship, different worlds.**

SupraCraft maintains open-source tools and infrastructure with project identities shaped by their domains and a shared emphasis on clear interfaces, reproducible releases, accessible documentation, and truthful public surfaces.

## Featured projects

- **[Bridge](https://github.com/SupraCraft/Bridge)** — post-compile Maven transformation tooling and a Java bytecode support library.
- **[VanillaCord](https://github.com/SupraCraft/VanillaCord)** — connects vanilla Minecraft servers to proxies with forwarded player identity.

Project documentation, releases, and product-specific public sites live with the projects themselves rather than being duplicated here.

## Explore SupraCraft

The full branded SupraCraft hub will live at **https://supracraft.github.io/**. Until that surface is published, GitHub's organization repository view remains the automatically current catalog of public work.
